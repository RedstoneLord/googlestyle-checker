## Описание функций и типов

`Problem`

**Поля:**

* `rule` - `string`, код правила (`NAME-FUNC`, `NAME-CONST`, `NAME-VAR`).
* `message` - `string`, текст сообщения.
* `line` - `number`, номер строки (с нуля).
* `start`, `end` - `number`, границы имени в строке.

`mask(lines)`

**Параметры:**

* `lines` - `string[]`, строки исходного кода.

**Вывод:** **`mask(lines)`** (string[]) строки той же длины, где комментарии (`//` и `/* */`) и содержимое строк заменены пробелами.

```
mask(['int a; // x', 'int b;']) = ['int a;     ', 'int b;']
```

`naming(text)`

**Параметры:**

* `text` - `string`, исходный код целиком.

**Вывод:** **`naming(text)`** (Problem[]) список найденных проблем с именами. Пустой, если всё в порядке. `main`, ключевые слова (`if`, `for`, `return` и т. д.) и строки с `const`, не похожие на объявление константы, не проверяются.

```
naming('int MyVar = 1;') = [{ rule: 'NAME-VAR', line: 0, start: 4, end: 9, ... }]
```

`masker(line, block)`

**Параметры:**

- `line` - `string`, одна строка кода.
- `block` - `boolean`, `true`, если строка начинается внутри блочного комментария.

**Вывод:** **`masker(line, block)`** (MaskedLine) объект с полями `text` (строка, где комментарии и содержимое строк заменены пробелами, длина не меняется) и `inBlock` (`true`, если блочный комментарий не закончился в конце строки). Экранированные символы внутри строк (например, `\"`) обрабатываются, кавычки остаются на месте. Используется в `mask()`.

```
masker('f("hi");', false) = { text: 'f("  ");', inBlock: false }
```

`problemer(rule, message, i, match)`

**Параметры:**

- `rule` - `string`, код правила.
- `message` - `string`, текст сообщения.
- `i` - `number`, номер строки.
- `match` - `RegExpExecArray`, результат регулярного выражения: группа 1 - всё до имени, группа 2 - само имя.

**Вывод:** **`problemer(rule, message, i, match)`** (Problem) проблема, где `start` - длина текста до имени, `end` - `start` плюс длина имени. Так подчёркивается именно имя, а не вся строка.

```
для строки 'int MyVar = 1;':
problemer('NAME-VAR', 'msg', 0, match) = { rule: 'NAME-VAR', message: 'msg', line: 0, start: 4, end: 9 }
```

`first(line)`

**Параметры:**

- `line` - `string`, строка кода.

**Вывод:** **`first(line)`** (string) первое слово строки или пустая строка, если слова нет (пустая строка, `}` и т. п.). Нужна, чтобы отличить объявление переменной от строк вида `return x;`.

```
first('  return x;') = 'return'
first('}') = ''
```
